# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within this repository, please do **not** open a public GitHub issue. 

Instead, please send an email directly to:
**Kid Omar Costelo** - `kidomarcostelo@gmail.com`

Please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions to reproduce the issue.
- Any suggested remediations if available.

We appreciate your responsible disclosure and effort to keep the project secure.
